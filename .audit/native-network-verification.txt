Implemented

- Separate application/environment secret keys; no hosted account requirement.

- Pinned HTTPS management for scoped sandboxes without local WireGuard or SSH.
- Cross-server channels/presence with bounded replay and internal SDK recovery.
- Locally generated typed HTTP contracts.
- Drain/resume with shared process leases, complete request accounting, bounded
  subprocess cancellation, primary management ownership and fresh-state promotion.
- Installer, CLI documentation and canonical/generated agent skills.
